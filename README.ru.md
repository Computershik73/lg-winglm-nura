# LG Wing (LM-F100N, «winglm») — порт postmarketOS / Nura

Порт postmarketOS на LG Wing (Snapdragon 765G / SM7250 «lito», телефон с
поворотным экраном): Phosh на обоих экранах, штатное ядро 4.19 из Android.
Разрабатывается и проверяется в повседневной работе на LM-F100N (корейская
модель) в сети МегаФон. postmarketOS с тех пор переименован в Nura; порт
использует его инструменты (pmbootstrap, pmaports).

[English version](README.md)

> **Состояние: работает как телефон.** Звонки (2G/3G и VoLTE), Wi-Fi,
> Bluetooth, звук, ускорение графики и оба экрана работают. Чего не хватает и
> что не проверено — в таблице ниже. Шероховатости будут: это порт на ядре из
> Android с большим количеством восстановленного по документации и
> дизассемблеру «клея».

### Что не работает или не доделано

Актуальное состояние — в issues; на момент написания:

* Сон (s2idle) — на этом ядре пока не работает.
* Громкость на громкой связи в звонке — сделано (усиление усилителя через
  `winglm-spk-gain`), в настоящем звонке ещё не проверено.
* Калибровка звука ACDB (настройки эхоподавления и шумоподавления из Android)
  не загружается.
* Камеры и сканер отпечатков (Qualcomm CamX / TEE) — не планируются.

## Сборка

### Пакет устройства и ядро (на ПК, pmbootstrap)

```sh
git clone https://github.com/Computershik73/lg-winglm-nura
cd lg-winglm-nura
pmbootstrap init                        # устройство: lg-winglm (после копирования ниже)
cp -r pmaports/device/testing/device-lg-winglm pmaports/device/testing/linux-lg-winglm \
      "$(pmbootstrap config aports)/device/testing/"
pmbootstrap checksum device-lg-winglm linux-lg-winglm
pmbootstrap build device-lg-winglm
pmbootstrap build linux-lg-winglm
```

### Форки Alpine (на телефоне)

Форки из `aports/` собираются на самом устройстве (кросс-компиляция
pmbootstrap для них не заработала, QEMU слишком медленный):

```sh
# на телефоне, с доступом в сеть
sudo apk add alpine-sdk && abuild-keygen -a -i
mkdir -p ~/aports && cp -r aports/<пакет> ~/aports/
cd ~/aports/<пакет> && abuild -r        # пакеты: ~/.local/share/abuild/aports/aarch64
sudo apk add ~/.local/share/abuild/aports/aarch64/<пакет>-*.apk
```

Если Alpine обновит один из этих пакетов, обновление заменит форк — тогда
его нужно пересобрать.

### Графика (Mesa с KGSL)

В Mesa из Alpine нет поддержки KGSL. `aports/mesa-kgsl` собирает ту же версию
Mesa с ней (turnip и freedreno на KGSL, zink для GL) в `/usr/lib/mesa-kgsl`;
его `/etc/ld-musl-aarch64.path` ставит этот каталог перед `/usr/lib`, а файл
ICD Vulkan указывает на его turnip. Mesa из Alpine остаётся установленной для
всего, что от неё зависит.

### Мобильный интернет (форк ModemManager)

Порт данных модема создаёт IPA-драйвер из Android (`rmnet_ipa0`, виртуальное
сетевое устройство, настраиваемое через ioctl драйвера). `aports/modemmanager`
добавляет его поддержку (патч 0100, создаётся скриптами из `tools/mm-patch/`),
правила udev из пакета устройства включают её. Дальше подключение мобильной
сети в NetworkManager работает как обычно (Wi-Fi остаётся основным маршрутом).

## Установка

**Прочитайте сначала.** В штатном загрузчике LG (ABL) нет режима fastboot:
работает только *fastbootd* в разделе recovery, в него попадают через
`adb reboot fastboot` из Android или штатного recovery. Оставьте `recovery_a`
штатным: это путь обратно в fastbootd. Перед прошивкой сделайте полную копию
(QFIL/EDL); `tools/edl-restore.ps1` восстанавливает `boot_a` через EDL.

* Корневая ФС ставится в раздел userdata (данные Android стираются).
* Командная строка ядра должна быть короче 511 символов: ABL LG берёт только
  поле cmdline из заголовка boot-образа, слишком длинная строка обрезает UUID
  корневого раздела.
* Никогда не добавляйте `video=Virtual-1:d` в командную строку (бесконечная
  перезагрузка).

Прошивки самого телефона (модем, ADSP, Wi-Fi, GPU, усилитель звука) берутся во
время работы из его разделов; бинарных файлов LG в репозитории нет.

## VoLTE

В прошивке модема LG нет IMS-клиента: на Android SIP ведёт IMS-приложение LG
на основном процессоре и управляет медиа-движком внутри модема. В этом порте
свой IMS-клиент (`winglm-volte`): поднимает IMS-канал, проходит
аутентификацию AKA по ISIM, настраивает IPsec, регистрируется и служит
SIP-шлюзом для GNOME Calls. Звук звонка обрабатывается в модеме (движок LG
«MMPF») и в голосовом тракте DSP — как на Android. Проверено в МегаФоне;
у других операторов могут понадобиться другие настройки. Подробности:
[docs/volte.md](docs/volte.md).

## Обратная разработка

Части, связанные с IMS/VoLTE, протокол медиа-движка модема и ряд шагов запуска
железа восстановлены по проприетарным библиотекам LG из Android и по
отладочным сообщениям модема — ради совместимости с устройством, которое уже
есть у владельца. Результаты описаны в `docs/`; проприетарного кода или данных
в репозитории нет.
